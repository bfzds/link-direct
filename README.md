# 链接直达助手

一款同时支持 Chrome 和 Edge 的浏览器插件（Manifest V3）：自动识别被网站包装的中转链接与短链接，点击一步直达真实地址，省掉「即将离开本站」确认页和二次跳转。

## 功能

| 功能 | 说明 | 默认 |
| --- | --- | --- |
| 跳过中转页直达 | 自动改写知乎、CSDN、掘金、简书、豆瓣、开源中国、百度等站点包装过的外链；打开中转确认页时自动跳走 | 开 |
| 短链接自动还原 | t.cn、url.cn、dwz.cn、bit.ly 等短链，点击时后台解析真实地址后直达 | 开 |
| 悬停预解析 | 悬停在短链上时显示真实地址（多一次网络请求，按需开启） | 关 |
| 纯文本网址可点击 | 页面里未做成链接的网址文本自动变成可点击链接 | 开 |

点击工具栏图标可随时开关各功能，并查看当前页面识别到的链接数量。

## 安装（Chrome / Edge 通用，同一份代码）

1. 打开扩展管理页：Chrome 地址栏输入 `chrome://extensions`，Edge 输入 `edge://extensions`
2. 打开右上角（Edge 为左下角）的 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本目录（`link-direct`）
4. 建议在扩展详情页里把「允许访问文件网址」也打开，本地 HTML 文件中的链接同样能被处理

安装后打开 `test/test.html` 可以快速自测三类功能。

## 支持新站点：只改 rules.js

所有站点规则集中在 [rules.js](rules.js)，文件内有详细的字段说明。例如要支持某个新网站的中转链接，往 `redirectRules` 里加一条：

```js
{ host: 'link.example.com', param: 'target' }
```

- 真实地址藏在 URL 参数里 → 用 `param` 写参数名
- 真实地址需要请求一次才知道（服务端 302 型）→ 用 `resolve: true`
- 新的短链服务 → 往 `shortLinkHosts` 数组里加域名

修改保存后，回到扩展管理页点击该扩展上的「刷新」按钮即可生效。

## 目录结构

```
link-direct/
├── manifest.json    # 扩展清单（Manifest V3）
├── rules.js         # 站点规则表（扩展新站点只改这里）
├── content.js       # 页面脚本：识别/改写链接、确认页自动跳、纯文本链接化
├── background.js    # 后台：解析 302 与短链的真实地址
├── popup.html/css/js# 工具栏设置面板
├── icons/           # 图标
└── test/test.html   # 本地测试页
```

## 已知说明

- 「短链还原」和百度搜索结果的直达需要在点击时发一次网络请求跟踪真实去向，会有可感知的一瞬延迟；解析失败时会退回打开原链接，不会让链接失效。
- 悬停预解析默认关闭，开启后每悬停一个短链都会发起一次解析请求。
- 个别由前端框架（React/Vue）强管理的页面，「纯文本网址可点击」可能引起页面异常，遇到时可在弹窗中单独关闭该功能，其余功能不受影响。
- 插件不收集、不上传任何数据；网络请求仅用于解析你点击的链接的真实地址，设置保存在浏览器本地。
